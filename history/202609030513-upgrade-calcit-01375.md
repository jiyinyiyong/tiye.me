# Upgrade to Calcit 0.13.75 / 升级 Calcit 0.13.75

## Summary / 概要

- Upgraded Calcit and `@calcit/procs` from 0.13.40 to 0.13.75, then refreshed the released Calcit dependency graph.
- 将 Calcit 与 `@calcit/procs` 从 0.13.40 升级到 0.13.75，并更新已发布的 Calcit 依赖图。
- Migrated the legacy `load-as-code` macro through the 0.13.51 compatibility toolchain and declared a strict `Macro` contract with the `:fs-read` capability.
- 使用 0.13.51 兼容工具链迁移旧 `load-as-code` 宏，并声明带 `:fs-read` 能力的严格 `Macro` contract。
- Narrowed the macro file path and browser keyboard-event key at their trusted boundaries, replaced a heterogeneous `merge` with `assoc`, and migrated deprecated `tag-match` calls to `match`.
- 在可信边界收窄宏文件路径和浏览器键盘事件 key，以 `assoc` 替代异构 `merge`，并将废弃的 `tag-match` 迁移到 `match`。
- Replaced the unresolved SSR string helper with the typed `.replace` method form.
- 将 SSR 中未解析的字符串辅助调用改为带类型信息的 `.replace` 方法形式。
- Migrated the generated quality baseline from JSON to Cirru EDN and marked generated text artifacts in `.gitattributes`.
- 将生成的质量基线从 JSON 迁移为 Cirru EDN，并在 `.gitattributes` 中标记生成文本。

## Validation / 验证

- `caps --ci`
- `yarn install --immutable`
- `calcit calcit.cirru edit format`
- `calcit calcit.cirru --check-only`
- `calcit calcit.cirru analyze deprecated`
- `calcit calcit.cirru analyze quality --baseline config/calcit-quality.cirru`
- `calcit calcit.cirru js`
- `yarn vite build --base=./` with Node.js 24
